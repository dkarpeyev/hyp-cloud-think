# QM: MEAS: IT — quanta as finite-memory devices

The idea has three parts. Below I make each one precise enough to check, say where it already agrees with known QM, and say where it would break. I also note what is already in THINK and which published work comes closest. The references are from memory and none of the papers are in THINK, so please check them.

**Already in THINK:** "QM: MEAS" (`claude-session-20261022-214006-50455e41.md`) covers POVMs and reconstructions of Hilbert space from axioms. "QM: MEAS: QBism" (`claude-session-20261021-081812-ec1e6abb.md`) treats collapse as an agent updating its beliefs. Your idea moves the updating agent down into the quantum itself, so it reads as QBism with every quantum as its own agent.

## 1. Precise version of the three claims

| Your claim | Formal version |
|---|---|
| A quantum is a small computer with limited memory | Each field mode carries a memory register M with a fixed capacity C bits |
| Being excited means having memory | The vacuum is the blank register. Occupation number n counts the records held in M, or is a function of them |
| Collapse goes to what the quantum already knows | When an entangling interaction offers outcomes i, the chance of outcome i falls as the memory-update cost ΔK_i grows, e.g. P(i) ∝ exp(−ΔK_i) |

## 2. Where the idea agrees with standard QM

**(a) The Born rule comes out as a special case.** Define the update cost as the surprisal, ΔK_i = −ln|⟨i|ψ⟩|². Then exp(−ΔK_i) = |⟨i|ψ⟩|², which is exactly the Born rule. So "minimize the memory update" is consistent with QM, provided the amplitude already encodes what the system "expects". Read this way, the state ψ is the content of the memory, and the Born rule is a Boltzmann distribution over update costs at temperature 1. Any other cost function would predict deviations from the Born rule, and those are tightly constrained by experiment.

**(b) Repeating a measurement already works this way.** In QM, measuring Z twice gives the same result with probability 1 (the Lüders rule), because the quantum "already knows". That fits your model exactly.

**(c) Limited memory is already a principle in QM foundations.**
- **Holevo bound:** a qubit can carry at most 1 classical bit. That is a sharp value for the capacity C.
- **Zeilinger–Brukner (1999):** "an elementary system carries one bit."
- **Rovelli, relational QM (1996), postulate 1:** a system holds only a finite amount of relevant information.
- **Spekkens toy model (2007):** a knowledge-balance principle, where at most half of the possible information can be known. This alone reproduces much of quantum phenomenology.

**(d) Monogamy of entanglement reads as a full memory.** A qubit that is maximally entangled with A cannot be entangled with B at all. In your language, its memory is used up by its record of A. This is probably the strongest structural support for the idea.

**(e) The closest published idea is Lee Smolin's "principle of precedence"** (arXiv:1205.3707, 2012). It proposes that a quantum system behaves the way similar systems behaved in the past: physical law as habit. That is "prefer what it already knows", with the memory spread over all past instances rather than stored in each quantum. Zurek's *predictability sieve* and einselection are also close. The pointer states that survive decoherence are the ones whose records in the environment change least.

## 3. Where the idea breaks, or has to be tightened

1. **Memory gets wiped by incompatible measurements.** Measure Z, then X, then Z again. QM says the last Z is 50/50: it keeps no trace of the first result. Sequential Stern–Gerlach experiments confirm this. So the memory cannot simply build up. It has to be **overwritten** by a measurement that doesn't commute with the earlier one, which is what you would expect with C ≈ 1 bit. Any lasting history dependence beyond that is a testable prediction, and it is probably already ruled out at the level of single particles.
2. **Bell's theorem rules out a classical, local memory.** If M is a classical register stored locally with the quantum, it is a local hidden variable, and Bell experiments exclude those. The memory therefore has to be **quantum**, so it can itself be in superposition and be entangled, or it has to be nonlocal. If it is quantum, "the record" is just the entanglement, and the model becomes a new way of describing QM rather than a new mechanism. That is fine if what you want is an interpretation.
3. **Particle number depends on the observer.** In the Unruh effect, an accelerated observer sees particles in the inertial vacuum. If being excited means having memory, then whether a mode has memory depends on the observer. This fits a relational, Rovelli-style reading, but it rules out memory as an absolute property.
4. **The vacuum is not blank.** The QFT vacuum is highly entangled across regions (the Reeh–Schlieder theorem). So "blank memory" has to mean "no records relative to a chosen set of modes", not "no correlations at all".
5. **Identical bosons.** Quanta of the same type cannot be told apart, so a memory cannot belong to an individual particle. It has to belong to a **mode**. This argues for putting M on modes, not particles: a Fock state |n⟩ would then mean "this mode holds n records".
6. **Coherent states** have no definite particle number. A laser mode is in a superposition of different amounts of memory, which again forces M to be quantum.

## 4. What would make it more than a reinterpretation

The idea makes new predictions only if the update cost ΔK differs from the surprisal in some regime. Possible places:
- **History dependence** past the Holevo capacity, as in Smolin's precedence. Look for bias toward earlier outcomes in systems with many degrees of freedom, which have room for more memory.
- **Thermodynamic cost.** By Landauer's principle, a memory update costs at least kT·ln2 per erased bit. If collapse really is an update, measurement should carry a minimum heat signature tied to the number of bits overwritten. This links to the GRW heating tests in your QBism note, where collapse models are constrained by spontaneous heating.

## 5. Suggested toy model

The aim is to find which constraints on C and ΔK are forced by known QM.

- One qubit mode with a memory of C bits.
- Interactions are CNOT-like couplings to an apparatus. The outcome rule is P(i) ∝ exp(−β·ΔK_i), with ΔK the change in description length of M.
- Questions to answer: for which C and β does the model reproduce (i) the Born rule, (ii) the 50/50 result in the Z→X→Z sequence, (iii) a violation of the Bell/CHSH inequality? My guess is that the answers are C = 1, β = 1, and quantum M, which would give a fresh derivation of known QM. Any extra freedom in the model points to a new prediction.

## What changes in the argument

- **Rovelli's postulate 2 is your overwrite rule.** In my earlier answer I said the memory must be *overwritten* by incompatible measurements, so that Z→X→Z comes out 50/50. Rovelli builds that in as an axiom: new information makes old information irrelevant. So the pair "limited memory + overwrite" is already in the literature as postulates 1 and 2 of relational QM.
- **A new source supports my Bell objection.** The critique [arXiv:2109.03186](https://arxiv.org/pdf/2109.03186) points out that Rovelli's two postulates also hold in the **Spekkens toy model**, which is a *local hidden-variable* theory. So finite memory plus overwrite does not give Bell violations. Something must be added: the memory has to be quantum, or nonlocal. This is the point I made in §3.2 of my earlier answer.
- **Choosing between two readings of Zeilinger.** Your idea needs a "memory capacity" reading, which the Holevo bound provides. Zeilinger's principle may be better read as a limit on what can be predicted. These are different claims, and the model should say which one it uses.
- **Smolin's paper fits your idea closely, with one difference.** Smolin keeps the memory in the ensemble of past instances, not inside each quantum. His paper also has a kinematic part ("freedom", built on the Masanes–Müller axioms) that I did not mention before.
